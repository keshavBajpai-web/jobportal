# Job Portal – MERN Stack

A full-stack job portal built with the **MERN stack**, where job seekers can search and apply for jobs, while recruiters can create companies, post jobs, and manage applications.

## 🚀 Features

* User authentication with JWT & bcrypt
* Recruiter & Job Seeker roles
* Job posting and job search
* Job filtering
* Apply for jobs
* Application status management
* Company management
* Profile & resume upload
* Cloudinary file storage
* Protected routes & role-based authorization

## 🛠️ Tech Stack

**Frontend:** React, Redux Toolkit, Tailwind CSS, React Router, Axios

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt, Multer

**Deployment:** Render, MongoDB Atlas, Cloudinary
